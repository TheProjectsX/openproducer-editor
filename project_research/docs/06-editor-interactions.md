# Exact editor interactions

The Video Studio Media tab places Sort and Filter icon menus beside Import media. Media shows only video, audio, and image assets, and its count excludes text titles. Text stays in the Text tab even when a saved project contains text assets and clips. Filter the local bin by All, Images, Videos, and Audio. Sort by time imported, file date, name, type, or duration, then choose ascending or descending order in the same menu. The icon buttons have accessible names, tooltips, and visible focus. File date means the source file's last-modified timestamp because browsers do not expose its creation timestamp. Assets without that metadata follow dated assets. Sorting changes only the visible bin order, preserving timeline clips and asset references.

Click a media tile to select it; Ctrl/Command-click toggles individual tiles and Shift-click selects the visible range from the last anchor. Holding the mouse button in blank media-bin space and dragging a rectangle selects intersecting tiles. A plain click in blank bin space clears selection. Select all and Deselect all are in the Your media header before the item count. Drag a selected tile to place the selected set in the order shown by the current sort. Images/videos are sequential on a visual lane; audio is sequential on an audio lane starting at the same project time, so an audio clip does not wait for the preceding visual clip. Starting a mixed drag requires a lane compatible with its first ordered item. A drop on an empty timeline starts at zero when no later time is chosen; an explicit lane drop honors the chosen time. A batch is one edit for undo and autosave. Keyboard focus plus Enter places the selected set at the playhead; Ctrl/Command/Shift+Enter changes tile selection.

Image and video thumbnails show the complete frame inside the media-bin and timeline boxes. Preserve aspect ratio, resize to fit, and leave empty space when the media ratio differs from the box; never crop or overflow a thumbnail.

The Video Studio timeline starts as an empty main drop area without numbered lane labels, vertically centered in the timeline viewport. The main lane accepts video and images and stays centered even when only audio clips are placed. Audio lanes appear directly below it only after audio is placed; overlay lanes appear directly above it for video, images, and text. Dropping audio on general timeline space creates Audio 1 at zero or appends to its end. Dropping audio on an existing audio lane honors the pointer time and uses a new lane if it overlaps. Visual media requires an explicit drop on a visual lane; keyboard activation places it at the chosen playhead time. Occupied lanes remain visible after project reload. Rendering continues to use the saved numeric track order, with higher visual tracks composited above the main lane.

Ctrl+wheel over the timeline scales clip widths around the time directly under the mouse pointer. The hovered time stays at that screen position while other clip edges and ruler marks move; the timeline provides enough horizontal scroll space to preserve this anchor even for short projects.

Text title clips can be dragged horizontally within their overlay lane. During a clip drag, an independent target above the lane stack accepts a drop to create the next overlay lane without shifting the existing lanes under the pointer. Text clips cannot be dropped onto the main visual or audio lanes.

Video Studio presents the media and creation browser, composite player, and contextual inspector in a compact three-pane desktop layout. A lower timeline remains visible while editing; export settings open as a dialog with a rendered-file preview and download action. Direct entry without a project offers local project creation. At narrow widths the panes stack while keeping each control reachable. The browser tabs expose only implemented local tools; unavailable AI and stock features are not shown as working controls.

The Library tab contains Image, Video, and Sound effects subtabs, separate from the local-import Media bin. Imported user files remain only in Media. The Image section shows a compact grid tile for a solid black color background, with a color-picker icon at the top right. Clicking the tile creates a local SVG image asset and a five-second Video 1 clip; the color icon changes the color first. The project stores the generated asset with the edit. Library image/video/sound catalog entries currently remain empty until that content is available.

Clicking an active title in the preview selects its clip and shows a canvas-aligned selection box. Drag the box to move the title, its corner handle to resize it, or the top handle to rotate it. Each gesture updates the clip transform used by preview and export and records one undo step when released.

Import media on a blank Video Studio route creates a local video project and saves selected assets in the media bin only. Click selects media; drag the selection onto a compatible track or focus a tile and press Enter to place it at the playhead. Import alone leaves the timeline empty. A timeline with no clips cannot play. The timeline ruler is a seek control: click or drag to seek, use arrow keys for one frame, Shift+arrow for one second, and Home/End for the bounds. The playhead handle can be grabbed and moved without jumping to the first pointer position. The player transport shows current/total timecode, previous/next frame, play/pause, and fullscreen.

## Shared numeric-control rule

Every adjustable numeric option has a labeled text or number field showing its unit, alongside an optional slider and preset buttons. Typing a value updates preview after validation; presets populate the same field. Display min/max and precision. Reject empty, non-finite, zero where invalid, negative where invalid, and out-of-range values with an inline message while retaining the last valid render value. Keyboard arrows, focus states, and screen-reader labels are required. Export must use the committed value, not a rounded slider value.

## Audio speed

User selects a clip or whole-file operation, types any decimal multiplier from 0.1× to 16×, and sees the calculated output duration. Preset buttons may include 0.5×, 1×, 2×, 4× but cannot constrain input. Pitch preservation is on by default. A toggle selects natural pitch change. Preview and exported audio must agree on duration and pitch mode. At extreme speeds, show quality guidance if processing creates artifacts; do not quietly clamp a valid typed value.

## Video timeline

Layout: media bin on the left, preview center, inspector on the right, timeline below. Users drag media into tracks and see thumbnails/waveforms. Timeline supports play/pause, seek, zoom, snap toggle, split at playhead, trim handles, drag/reorder, duplicate, delete, undo/redo, and keyboard shortcuts. The inspector shows exact numeric controls for selected clip transform, opacity, volume, speed, fade, transition, and effect values.

The player offers Original, common canvas ratios, and Custom width/height. Original follows the first placed video or image clip's aspect ratio. Preview fits the entire output canvas within the player, and each visual source fits inside that canvas unless the user explicitly changes scale/position. Ctrl+wheel above the timeline zooms its time scale around the pointer; the typed zoom field remains available.

Video Studio keyboard shortcuts: Space toggles playback even when a button, media tile, or other non-text control has focus, without activating that control; repeated keydown events from holding Space do not repeat the toggle. Text entry keeps normal Space behavior. Left/Right Arrow seeks one frame (Shift seeks one second); Home seeks to the start; S splits the selected clip at the playhead; Delete/Backspace removes the selected clip; Ctrl/Cmd+Z undoes; Ctrl/Cmd+Shift+Z or Ctrl/Cmd+Y redoes. Clicking any point on the timeline ruler moves the playhead there and pauses playback; dragging along the ruler continues to scrub.

The ruler keeps the regular cursor while hovering over time marks. Hovering over its usable time range shows a temporary vertical guide from just below the pointer through the visible timeline tracks. The guide follows horizontal pointer movement and disappears on pointer exit or click. The playhead and other horizontal-only handles use the column-resize cursor; vertical-only crop handles use the row-resize cursor. Two-axis move areas keep their move cursor.

With a video clip selected, the inspector can detach its primary audio into an editable WAV clip, or place any imported audio asset on Audio 1 at a custom offset and matching clip speed. Replacing audio mutes the detached primary-audio clip corresponding to that same video placement; other soundtrack clips remain unchanged. When a detached audio clip is selected, the inspector identifies its source and states that later video speed edits do not change the independent audio clip.

Video speed is per clip, 0.1×–16×, with custom decimal input. A speed change updates clip length and downstream positions according to the chosen ripple-edit mode; default is ripple on for a primary video track and off for overlays/audio. Attached audio remains synchronized and pitch-preserved by default. Detaching audio creates an independently editable audio clip with its current timeline alignment. If the clip's speed changes after detachment, the detached audio does not automatically change; the UI must make this visible.

Keyframes are supported for position, scale, rotation, opacity, and volume. A property without keyframes uses one constant value. Adding a keyframe at the playhead captures the current value. Values between keyframes interpolate linearly; before the first and after the last, hold the nearest value. Keyframes move with their clip. Initial transitions are cut, dissolve, and crossfade with a custom duration, limited to the available overlapping media. The current editor exposes “Dissolve into next clip” and “Crossfade into next clip” actions that create overlap with the next clip on the same track and apply linear fades. The preview and renderer must share the same timing/effect functions.

M6 browser fixture check (2026-11-14): the current editor exposes typed source in/out and timeline-start fields, track assignment, clip move, title/effect/transform controls, keyframes, dissolve, crossfade, per-clip speed and pitch mode, detach-audio, and render. A React event-value capture bug in the playhead field and a 1× Bungee transient-loss bug were found and fixed during the local fixture run. Drag-trim handles, primary-track ripple behavior, keyboard shortcuts, and imported-audio replacement are implemented, but direct interaction verification remains open. Ripple is enabled by default on Video 1 and can be switched off; it does not move overlays or audio. Cross-browser keyboard/accessibility coverage remains an implementation or release gap; this note does not waive the interaction requirements above.

Timeline coordinates use the horizontally scrolling `.timeline-scroll` viewport when seeking or moving clips, and ruler zero aligns with the start of each track lane after the sticky track-label gutter. Clip drops preserve the pointer's grab offset within the clip. Regression tests cover scrolled pointer positions, ruler alignment, and drop positioning.

Dragging an existing clip or a media-bin item onto a compatible track shows a placement preview. With Snap enabled, a clip edge within the typed tolerance joins the adjacent clip edge. Hovering over the first half of an occupied clip inserts before it; hovering over the second half inserts after it. Dropping into a free gap keeps that time unless an edge is close enough to snap. An insertion shifts later clips on that track just enough to make room, and the placement is one undoable edit. Snap off preserves the hovered time in free space but still inserts before or after an occupied clip to prevent overlap. Media-bin drag uses pointer movement so placement works without relying on the browser's native file drag transfer.

For a selected video clip, Basic exposes thin controls for scale, rotation, and audio volume with three-decimal readouts; six canvas alignment actions; horizontal/vertical mirror; silence audio; extract audio; replace audio; split; and duplicate. Audio clips expose the same volume control. Gain ranges from 0× to 4×; preview uses a local Web Audio gain stage and export applies the same per-clip gain before project peak protection. The Track and Timeline start fields share a row, as do Source in/out, below Audio volume. These edits target only the selected clip and are saved in the timeline project. Alignment positions visual bounds against the project canvas; center/middle resets the corresponding position coordinate. Audio clips and video clips with embedded audio show locally decoded peak waveforms at up to 16 buckets per second, normalized to each source's peak and reduced to the clip's on-screen width. Video waves use a compact strip and follow the clip's trimmed source range. Unsupported or silent streams have no fabricated waveform. Inspector scrollbars use a 7 px custom dark thumb.

Clicking any non-clip space in the timeline scroll area, including empty lanes, lane labels, spacers, and ruler, clears the selected timeline clip. Clicking a clip keeps it selected. Split uses the selected clip when present; with no selection it splits the Video 1 clip under the playhead, then selects the new right segment. The timeline toolbar's Delete Left/Right actions remain enabled and choose the most recently hovered clip first, then selected clip, then the Video 1 clip under the playhead. They trim that clip to the right or left side of the playhead respectively; Delete Left shifts the kept source range back to the clip's original timeline start to close the removed section, and ripple shifts later Video 1 clips left when enabled. If the whole clip is on the named deletion side, the action removes it, and if there is no content on that side it shows a brief message. The selected target remains identified by clip ID, and the status reports the affected asset name. The icons show a playhead divider, the retained clip segment, and an X over the removed side. Checkbox sizing is independent of numeric timeline inputs.

Quick video tools (Trim, Merge, Remove Audio, Replace Audio) create or open a Video Studio project with a focused inspector and prearranged track state. Users can switch to the full timeline without losing changes. The first release includes text titles, basic filters/color adjustments, and export controls; it does not include auto captions or an effect marketplace.

## Image resize and collage

Show original width/height and editable output width/height. Default **Match aspect ratio = off**. With it off, width and height are independent and the full image stretches to the exact output canvas with no crop or padding. Example: 400×340 to 300×300 gives an exactly 300×300 file, possibly with changed proportions. With it on, changing one dimension recalculates the other using the original aspect ratio and integer rounding. Toggling it on immediately reconciles dimensions using the last-edited field. Crop is a separate explicit tool.

Collage begins from a layout template but remains editable: add/remove/reorder images, adjust cell fit, spacing, background, canvas size, and text. Dragging a photo within its cell pans it; dragging it across a cell boundary moves it into an empty cell or swaps it with the occupied destination. Provide a keyboard-operable cell-position selector for the same move/swap behavior. Offer a compact background preset palette while retaining the custom color picker. Save cell positions and source references rather than flattening until export. Provide a before/after or original/output comparison for filters and resizing.

## AI image upscaling

Display model download size and readiness before starting. Offer 2×/4× buttons plus custom target width/height. The super-resolution model produces its supported scale; a final deterministic resample reaches a custom target. Preserve aspect by default in AI Upscale unless the user disables Match aspect ratio, in which case final resampling may stretch. Show estimated output size, tile progress, cancellation, and a zoomed before/after comparison. Model failure leaves the original and project intact.

## Export interaction

Show output format choices only after checking the browser/device. The export sheet lists exact dimensions, frame rate or sample rate, bitrate/quality, estimated duration/file size when feasible, destination filename, and a warning for unsupported combinations. Progress can be cancelled. On completion, offer download and keep the editable project. Do not auto-replace the source asset.

Video Studio preview and export include source audio from placed video clips. Clip mute, volume, speed, and fades apply to that audio. Detach and replacement actions mute the selected video's original audio to prevent duplicate playback. Audio files remain independently placeable on audio tracks. Importing a file only adds it to the media bin; playback stays disabled until a clip is placed.

The timeline toolbar uses thin vertical separators between the title and side-delete controls, history actions, clip-edit actions, snap/ripple toggles, and timeline numeric controls. Separators have balanced horizontal margins for clear grouping.
